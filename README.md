---

## 一、使用技术

| 分层 | 具体技术 |
| --- | --- |
| 结构 | 原生 **HTML5**，语义化标签（`header` / `nav` / `main` / `section` / `article` / `aside` / `footer`） |
| 样式 | 原生 **CSS3**：自定义属性（CSS 变量）、Grid、Flexbox、`clamp()` 流体排版、媒体查询、`backdrop-filter`、`prefers-reduced-motion` |
| 脚本 | 原生 **JavaScript**（ES5 语法，兼容性好），无框架、无构建步骤 |
| 交互 | 9 项交互全部由手写 JS 实现，未使用 jQuery 等库 |
| 依赖 | **零第三方依赖**：不加载任何 CDN、字体库、图标库或图片文件 |

**为什么选"原生组"**：这个页面结构并不复杂，用原生实现体积最小、打开最快，也更能体现对
HTML / CSS / JavaScript 本身的掌握，而不是对框架 API 的熟悉。整个项目没有 `npm install`，
没有打包产物，浏览器直接就能跑。

## 二、项目结构

```
mo-intro/
├─ index.html              入口文件：全部页面结构（已按板块分节并注释）
├─ assets/
│  ├─ css/
│  │  └─ style.css         全部样式（配色集中在文件开头 :root 变量里）
│  ├─ js/
│  │  └─ main.js           全部交互逻辑（每项交互都有编号注释）
│  └─ img/
│     └─ favicon.svg       资源文件：网站图标（本人手写的 SVG）
├─ serve.js                可选的本地预览服务器（只用 Node 内置模块，60 余行）
└─ README.md               本文件
```

结构、样式、脚本分别放在独立文件中，符合"结构 / 表现 / 行为"分离的要求。

**关于"原生项目应包含的文件"**：本项目按**原生组**要求提交，已包含

| 要求 | 本项目对应文件 |
| --- | --- |
| 入口 HTML 文件 | `index.html` |
| 所需 CSS | `assets/css/style.css` |
| JavaScript | `assets/js/main.js` |
| 图片 / 资源文件 | `assets/img/favicon.svg`（网站图标） |

**没有 `package.json`，这是刻意的**：`package.json` 是 Vue3 等需要脚手架 / 构建工具的方案的必需文件，
原生组不需要任何构建步骤，加了反而多余。同样，本项目不使用任何位图素材（所有视觉元素都由 CSS 绘制
或手写 SVG），因此没有多余的图片目录——这是"零依赖"这一设计选择的直接结果，不是文件缺失。

## 三、运行方式

**方式一：直接打开（最简单，无需任何环境）**

双击 `index.html`，用浏览器打开即可。

**方式二：本地服务器（推荐，更接近线上环境）**

需要本机已安装 Node.js。在本目录下执行：

```bash
node serve.js
```

然后在浏览器访问 <http://127.0.0.1:5188/> 。换端口：`node serve.js 3000`；停止：`Ctrl + C`。
`serve.js` 只是本地预览用的小工具，不是网站运行的必要条件。

## 五、实现的交互效果（共 9 项，全部为 JavaScript 交互）

| # | 交互 | 位置 | 实现说明 |
| --- | --- | --- | --- |
| ① | **Tab 切换** | 「竞赛荣誉与技能现状」 | 点击标签在两个面板间切换；支持 `←` `→` 方向键切换；带 `role="tablist/tab/tabpanel"`、`aria-selected`、`aria-controls` 无障碍属性；切换时面板有淡入上移动画 |
| ② | **折叠 / 展开** | 奖项卡片标题 | 点击展开该奖项的备赛细节与"收获"，箭头图标同步旋转，`aria-expanded` 同步更新 |
| ③ | **动态时间轴** | 「未来规划」 | 四个阶段可逐个点击展开/收起，展开时时间轴上的节点圆点同步点亮（发光效果） |
| ④ | **回到顶部** | 右下角悬浮按钮 | 滚动超过一屏后淡入出现，点击平滑滚回顶部；同时把焦点交还导航栏，方便键盘继续操作 |
| ⑤ | **滚动进度条 + 导航高亮** | 顶部导航 | 顶部细进度条实时反映阅读进度；导航栏自动高亮当前所在板块（滚动联动） |
| ⑥ | **移动端汉堡菜单** | 顶部导航（窄屏） | 点击展开/收起，图标变为叉号；支持按 `Esc` 或点击空白处关闭 |
| ⑦ | **滚动出现动画** | 全站 | 元素进入视口时淡入上移，使用 `IntersectionObserver`，只触发一次 |
| ⑧ | **终端名片逐行浮现** | 首屏 | 名片内容按顺序逐行出现，模拟命令逐条执行的效果 |
| ⑨ | **鼠标跟随光晕** | 全站背景 | 桌面端指针设备生效，触屏设备自动关闭（`pointer: fine` 检测） |

> 说明：⑤⑥⑦⑨ 属于页面体验类交互，①②③④ 是明确的功能型交互（Tab、折叠、时间轴、回到顶部）。

## 六、我实现的特色内容

1. **终端风格个人名片（首屏）**
   用纯 HTML + CSS 模拟了一个终端窗口：macOS 三色按钮、等宽字体、提示符配色、JSON 语法高亮、
   闪烁光标。把"年级 / 班级 / 专业 / 在学 / Python"和两个奖项分别放进 `whoami`、
   `cat profile.json`、`ls achievements/` 三条"命令"的输出里，比平铺一整块信息更好读。

2. **把话说实，不把简历写满**
   「关于我」里直接写了"目前的真实水平是能看懂论文里的模型结构，还写不出自己的"；
   「技能现状」里正在学但还没掌握的条目用**虚线框**标出，并补了一句"上面没写进去的，就是我目前还不会的"。
   我认为把能力边界画清楚，比堆砌关键词更有说服力。

3. **无障碍（Accessibility）细节**
   Tab 与折叠面板都实现了完整的 ARIA 状态同步；所有装饰性元素加 `aria-hidden`；
   键盘焦点有独立的青色描边样式（`:focus-visible`）；遵循系统的"减弱动画"设置
   （`prefers-reduced-motion`），开启后关闭全部动画。

4. **零依赖也做出质感**
   页面里所有视觉元素——终端窗口、圆点、箭头、分隔线、光晕、网格背景、网站图标——
   全部由 CSS 绘制或手写 SVG 生成，没有一张位图、没有一个图标字体。箭头就是"两条边框 + 旋转 45°"。
   唯一的外部资源是 `assets/img/favicon.svg` 这一个几行的矢量图标文件。
   好处是断网也能完整显示，加载几乎无等待。

5. **响应式适配**
   桌面端首屏与「关于我」为左右双栏，窄屏自动变单栏；导航在 960px 以下收成汉堡菜单；
   兴趣卡片、技能卡片使用 `auto-fit` 网格自动决定列数，360px 宽的手机上也不会横向溢出。

## 七、第三方资源来源说明

**本项目没有使用任何第三方库、图标库、字体库、图片素材或参考代码。**

- 字体：只使用系统自带字体（`PingFang SC` / `Microsoft YaHei` 等系统字体栈与等宽字体），未引入外部字体。
- 图标：箭头、圆点、三角等全部用 CSS 绘制（边框 + `transform: rotate()`），未使用图标字体或 SVG 图标库。
- 图片：项目内**没有任何位图图片**。唯一的资源文件是 `assets/img/favicon.svg`——本人手写的几行 SVG
  （圆角矩形 + "章"字），用作浏览器标签页图标。它不是下载来的素材，矢量格式任意缩放都清晰。
- 参考代码：无。页面结构与样式均为本人设计，交互逻辑为本人编写。

## 九、如何修改内容

- 改文字：直接编辑 `index.html`，各板块都有 `<!-- ============ 板块名 ============ -->` 注释分隔。
- 改配色：编辑 `assets/css/style.css` 开头的 `:root` 变量，例如把主强调色换成橙色：
  ```css
  :root{
    --cyan:#ff8a3d;    /* 主强调色 */
    --violet:#ff5f57;  /* 次强调色 */
  }
  ```
- 加一个兴趣卡片：复制 `#interests` 里对应分组的 `<article class="card">…</article>`，
  改标题、标签和文字，`--accent` 换成喜欢的颜色。
- 加一个技能条目：复制 `#panel-skills` 里的 `<span>…</span>` 即可；
  还没掌握的加 `class="wip"`（会显示成虚线框）。
- 加一个时间轴阶段：复制 `#future` 里整个 `<li class="tl-item">…</li>`，
  注意同步修改 `aria-controls` 与内容块的 `id`（如 `tl-body-5`）。
