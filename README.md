# 章熊耀 · 个人介绍页

一个用于**社团招新自我介绍**的单页网站：纯 HTML / CSS / JavaScript 手写，零第三方依赖、无需构建。
深色科技风，桌面端和手机端都已适配。

## 文件结构

```
mo-intro/
├─ index.html              页面内容（文案都在这里改）
├─ assets/
│  ├─ css/style.css        样式（颜色统一在文件开头 :root 里改）
│  └─ js/main.js           交互（滚动动画、导航高亮、鼠标光晕）
├─ serve.js                本地预览用的零依赖小服务器
└─ README.md               本文件
```

## 怎么看效果

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开就行，不需要任何环境。

**方式二（推荐，本地服务器）**：在 `mo-intro` 目录下执行

```bash
node serve.js
```

然后浏览器打开 http://127.0.0.1:5188/ 。换端口：`node serve.js 3000`。
按 `Ctrl + C` 停止。

## 常用修改示例

**换主题色**：打开 `assets/css/style.css`，改开头的变量即可，例如把强调色换成火影橙：

```css
:root{
  --cyan:#ff8a3d;    /* 主强调色 */
  --violet:#ff5f57;  /* 次强调色 */
}
```

**加一张自己的照片**：把图片放进 `assets/`，然后在 `index.html` 首屏的终端卡位置替换成 `<img>`，或加一个新的 `<section>`。

**加一个游戏 / 一部动漫**：在 `#interests` 里找到对应分类的 `<div class="cards">`，复制里面任意一个 `<article class="card">...</article>`，改标题、标签和文字，`--accent` 换成你喜欢的颜色。

**加一个兴趣分类**：复制整个 `<div class="group reveal">...</div>` 块，改分类名（`<h3>`、`group-en`、`group-count`）和里面的卡片。只有一张卡片时，给 `<div class="cards">` 加上 `cards-single`，避免卡片被横向拉满。

## 怎么发布到公网（以后需要时再看）

这个站是纯静态文件，把 `index.html` 和 `assets/` 一起上传即可：

- **GitHub Pages**：新建仓库 → 上传这些文件 → Settings → Pages → 选 `main` 分支根目录。
- **Netlify / Vercel**：把 `mo-intro` 整个文件夹拖进它们的网页上传区，几秒出网址。
- **自己的服务器（Nginx 等）**：把文件放进网站根目录就行。

`serve.js` 只是本地预览用的，不用上传。
